# Контекст Продукту

## Проблема
Користувачі macOS не мають простого способу моніторити споживання енергії своїх комп'ютерів в реальному часі. Хоча існує утиліта `macmon`, вона працює тільки в терміналі і не інтегрована в системний UI.

## Рішення
PowerBar надає зручний menu bar додаток, який:
- Показує поточне споживання енергії (watts)
- Автоматично оновлюється
- Не заважає роботі користувача
- Використовує точні дані з macmon

## Цільова аудиторія
- Розробники, які хочуть моніторити ресурси
- Користувачі, що дбають про енергоефективність
- Power users macOS

## Ключові метрики з macmon
- `all_power` - загальне споживання
- `cpu_power` - споживання CPU
- `gpu_power` - споживання GPU
- `ram_power` - споживання RAM
- `sys_power` - системне споживання

## Користувацький досвід
1. Запуск додатку
2. Автоматичне з'явлення в menu bar
3. Відображення актуального значення споживання
4. Можливість побачити деталі при кліку (опціонально)
