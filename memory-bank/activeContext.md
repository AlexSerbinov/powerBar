# Активний Контекст

## Поточний фокус
Виправлення багів PowerBar та додавання нового функціоналу:

### 🐛 Критичні баги для виправлення:
1. **PATH проблема**: PowerBar.app не знаходить macmon через обмежений PATH
2. **Неправильна метрика**: Показує `all_power` замість `sys_power`

### 🚀 Нові функції:
1. **Кастомний інтервал**: Можливість змінювати інтервал macmon (100, 250, 500, 1000, 2500ms)
2. **Всі метрики**: Показ повних даних macmon по правій кнопці миші

3. ⚙️ Додати налаштування інтервалу оновлення

## Останні рішення
- PowerBar.app успішно встановлений в /Applications
- Виявлена PATH проблема при запуску як .app
- Користувач хоче sys_power як основну метрику
- Потрібен configurable інтервал для macmon
