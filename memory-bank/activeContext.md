## Останні зміни (17.01.2025)

### Додані функції:
- **Average mode**: Збирання історії значень і показ середніх за періоди
- **Display mode switching**: Можливість перемикання між Instant та Average
- **Debug logging**: Додано логи для відстеження поточного режиму
- **Simplified menu**: Прибрано зайві опції як просив користувач

### Технічні деталі:
- Додана enum `DisplayMode` з `.instant` та `.average(seconds: Int)`
- Додана структура `PowerReading` для зберігання історії
- Метод `calculateAverage(for seconds: Int)` для обчислень
- `setDisplayMode()` метод для зміни режиму

### Debug інформація:
З логів видно що:
- PowerBar успішно запускається та отримує дані з macmon
- Режим завжди залишається `instant` навіть після вибору average
- Значення sys_power правильно відображаються (13-27W діапазон)
