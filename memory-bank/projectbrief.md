# PowerBar - Проєктна Структура

## Опис проєкту
PowerBar - це macOS menu bar додаток, написаний на Swift, який відображає поточне споживання енергії комп'ютера в реальному часі.

## Основні вимоги
- Відображення power consumption в menu bar
- Отримання даних з командної утиліти `macmon pipe`
- Оновлення даних з інтервалом macmon (за замовчуванням 1000ms)
- Мінімалістичний дизайн в menu bar
- Підтримка macOS

## Технічні вимоги
- Swift + SwiftUI
- AppKit для menu bar інтеграції
- Інтеграція з зовнішнім процесом `macmon pipe`
- JSON парсинг даних від macmon

## Основні компоненти
1. Menu Bar додаток
2. Процес менеджер для запуску macmon
3. JSON парсер для метрик
4. UI компонент для відображення

## Цілі користувацького досвіду
- Швидкий доступ до power consumption
- Ненав'язливе відображення в menu bar
- Точність даних в реальному часі
